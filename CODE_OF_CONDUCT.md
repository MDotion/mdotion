# Code of Conduct

MDotion adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be respectful and welcoming, assume good intent, accept constructive feedback gracefully, and focus on what is best for the project and its community. Harassment, insulting or derogatory comments, personal or political attacks, and publishing others' private information are not acceptable.

## Scope

This code of conduct applies in all project spaces — issues, pull requests, discussions and any other channel used by the project — and when an individual is officially representing the project.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately through their GitHub profile ([@SebastianI5](https://github.com/SebastianI5)). Reports will be reviewed promptly and handled confidentially.

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code of conduct, and may temporarily or permanently ban contributors for behaviour they deem inappropriate, following the enforcement guidelines of the Contributor Covenant.
